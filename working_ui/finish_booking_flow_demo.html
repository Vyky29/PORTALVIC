What happens in production

  1. Parent books a slot → fills registration form.
  2. Admin opens Participant documents → Accept.
  3. Parent gets email/WhatsApp with a finish-booking link.
  4. Parent chooses funding → booking length → payment → pays first instalment.
  5. Parent receives Parent Portal PIN.

# NEST letter templates (Word)

Put the editable **Employer notice** Word pack from NEST here after you download it from your NEST account / communications toolkit.

Suggested filenames:

- `NEST-employer-notice-templates.docx` — official editable letters
- Any filled clubSENsational master copies (e.g. `clubSENsational-enrolment-notice-master.docx`)

Official download entry point:

https://www.nestpensions.org.uk/schemeweb/nest/employers/managing-scheme/communication/duties.html

Also available from the NEST popup button **Employer notices** during employer setup.

Guides already stored one level up in `docs/hr/nest/`:

- `NEST-telling-staff-enrolling-new-worker.pdf`
- `NEST-guide-to-employer-notices.pdf` (if present)
- `nest-employer-notices-howto.html`
